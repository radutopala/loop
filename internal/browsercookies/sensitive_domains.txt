# Sites whose cookies stay unchecked by default in the import picker.
#
# Format: "<category> <domain>", one per line. A domain matches itself and
# every subdomain, so "okta.com" covers "example.okta.com".
#
# Categories: email, signin, bank.
#
# This list exists for what patterns cannot infer — n26.com and affirm.com do
# not look like banks to a regex. Anything catchable by a rule (login.*,
# *.duosecurity.com, *banking*) belongs in classify.go instead, not here.
# Users can extend it without a release via browser.cookie_import.
# sensitive_domains in ~/.loop/config.json.
#
# Keep it international, not local: a shipped list cannot hold every country's
# retail banks, and the ones a contributor happens to bank with say more about
# the contributor than about the user. Local institutions go in config.
