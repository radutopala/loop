# Tetris

Classic Tetris. Clear lines by filling complete rows. The game speeds up every 10 lines cleared. A ghost piece shows where the current piece will land.

## Controls

- **Arrow Left / Right** -- Move piece sideways
- **Arrow Down** -- Soft drop (scores 1 point per cell)
- **Arrow Up** -- Rotate piece
- **Space** -- Hard drop / Start the game
