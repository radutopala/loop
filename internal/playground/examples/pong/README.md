# Pong

Two-player Pong. First to 7 points wins. If Player 2 does not press any keys, the CPU takes over the right paddle automatically.

## Controls

- **W / S** -- Player 1 paddle (left side)
- **Arrow Up / Arrow Down** -- Player 2 paddle (right side)
- **Space** -- Start or restart the game
